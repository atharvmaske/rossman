# Rossmann Store Sales Prediction

## Overview
Built a machine learning-based sales forecasting system using the Rossmann Store Sales dataset from Kaggle.  
The project predicts daily retail store sales using historical sales and store information.

The project covers:
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Model training and evaluation
- Streamlit-based deployment

---

## Features
- Predicts store sales using ML models
- Interactive Streamlit web application
- Multiple regression models tested
- Complete end-to-end ML workflow

---

## Run Locally

Install dependencies:

```bash
pip install -r requirements.txt
```

Train model:

```bash
python train_model.py
```

Run Streamlit app:

```bash
streamlit run app.py
```
